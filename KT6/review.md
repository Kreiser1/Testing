## 2. Журнал запросов

Для сравнения PATCH и PUT созданы две записи с одинаковым исходным состоянием.

| Запрос и тело                                                       | Условный ответ                                                  | Состояние после запроса                       |
| ------------------------------------------------------------------- | --------------------------------------------------------------- | --------------------------------------------- |
| `POST /todoitems` <- `{"name":"patch-original","isComplete":false}` | `200 OK`; `{"id":1,"name":"patch-original","isComplete":false}` | Создана A, ID `1`                             |
| `POST /todoitems`<- `{"name":"put-original","isComplete":false}`    | `200 OK`; `{"id":2,"name":"put-original","isComplete":false}`   | Создана B, ID `2`                             |
| `POST /todoitems` <- `{"name":"patch-original","isComplete":false}` | `409 Conflict`                                                  | Дубликат не создан; A остаётся с ID `1`       |
| `PATCH /todoitems/1` <- `{"isComplete":true}`                       | `200 OK`                                                        | A: `name="patch-original"`, `isComplete=true` |
| `GET /todoitems/1`                                                  | `200 OK`; `{"id":1,"name":"patch-original","isComplete":true}`  | Подтверждено: PATCH сохранил имя              |
| `PUT /todoitems/2` <- `{"isComplete":true}`                         | `200 OK`                                                        | B: `name=null`, `isComplete=true`             |
| `GET /todoitems/2`                                                  | `200 OK`; `{"id":2,"name":null,"isComplete":true}`              | Подтверждено: прежнее имя не сохранилось      |
| `GET /todoitems/complete`                                           | `200 OK`; содержит A и B, у обеих `isComplete=true`             | Фильтр возвращает только завершённые задачи   |
| `DELETE /todoitems/1`                                               | `200 OK`                                                        | A удалена                                     |
| `GET /todoitems/1`                                                  | `404 Not Found`                                                 | A отсутствует                                 |
| `DELETE /todoitems/1`                                               | `404 Not Found`                                                 | A отсутствует                                 |
| `GET /todoitems/1`                                                  | `404 Not Found`                                                 | A отсутствует                                 |

## 4. Утверждения

**Подтверждённое в рамках теста:** `GET /todoitems/complete` вернул `200 OK`, и все элементы ответа имели `isComplete=true`. В контрольной выборке присутствовали записи `1` и `2`, обе со статусом `true`.

**Сортировка:** один полученный список не доказывает гарантию порядка элементов. Уточнить: по какому полю, в каком направлении и для каких списковых эндпоинтов должна гарантироваться сортировка?

**Самое опасное замечание:** поведение PUT при пропущенном `name`, потому что клиент может рассчитывать на сохранение прежнего значения, а фактически потерять данные.
