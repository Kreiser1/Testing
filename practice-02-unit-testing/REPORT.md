- Скидка 5% для 5000 включительно
    - 5000, false, false
    - Ожидаемый результат: 5000 - 5% (доставка бесплатно) = 4750
    - Фактический результат: 5000
    - Order_5000WithoutLoyalty_TotalIs4750

    - Ожидаемый результат: 4000 + 500 = 4500
